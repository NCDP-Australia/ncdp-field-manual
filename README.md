# NCDP Field Manual — moved

> **This repository is archived.** The NCDP Field Manual is now part of the
> **[NCDP Data Standards and Procedures](https://github.com/NCDP-Australia/ncdp-standards)**,
> versioned and released with them.

| | |
|---|---|
| Read the current Field Manual | [ncdp-standards wiki → Field Manual](https://github.com/NCDP-Australia/ncdp-standards/wiki/Field-Manual) |
| PDF and Word version of the current revision | [ncdp-standards releases](https://github.com/NCDP-Australia/ncdp-standards/releases/latest), or Contribute → Guides on [ncdp.auscope.org.au](https://ncdp.auscope.org.au/contribute/guides) |
| Cite the current revision | [doi.org/10.5281/zenodo.23127540](https://doi.org/10.5281/zenodo.23127540) (always the latest revision; each revision also has its own DOI) |
| Propose a change | Edit the Word original `source/NCDP_Field_Manual.docx` in [ncdp-standards](https://github.com/NCDP-Australia/ncdp-standards) (see its README) |

## The first edition (v1.0)

The files in this repository are the last standalone copy of the manual: edition **v1.0 (2026-09-15)**
with the small corrections made since. Edition v1.0 remains citable:

> Ierodiaconou, D., Allan, B., & Nuyts, S. (2026). *National Coastal Drone Program (NCDP) Field
> Manual* (v1.0). Zenodo. https://doi.org/10.5281/zenodo.22867527
