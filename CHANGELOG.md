# Changelog

Each edition has its own DOI. To cite the manual in general, use the
concept DOI [10.5281/zenodo.22867526](https://doi.org/10.5281/zenodo.22867526),
which always resolves to the latest edition.

## v1.0 — 2026-09-15

DOI: [10.5281/zenodo.22867527](https://doi.org/10.5281/zenodo.22867527)
(archived on Zenodo 2026-09-21)

First public release.

- Replaced the provisional "Imagery Upload" method (zip to a shared cloud
  folder, metadata via a Microsoft Form) with the NCDP intake portal at
  ncdp.auscope.org.au: registration, the per-organisation airframe registry,
  report-first metadata capture, automated QA/QC, and what the warnings mean.
- Added a References section, and cited Ierodiaconou et al. (2022) in
  "How It Works" as the published account of the citizen science UAV approach
  the manual is built on.

Note: the table of contents page numbers are as exported. Open the .docx in
Word and refresh the field (Ctrl+A, F9) if they need to be exact after
further edits.
