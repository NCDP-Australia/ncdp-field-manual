# Changelog

## v1.0 — 2026-09-15

First public release.

- Replaced the provisional "Imagery Upload" method (zip to a shared cloud
  folder, metadata via a Microsoft Form) with the NCDP intake portal at
  ncdp.auscope.org.au: registration, airframe registry, report-first
  metadata capture, automated QA/QC, and what the warnings mean.
- Added a References section, and cited Ierodiaconou et al. (2022) in
  "How It Works" as the published account of the citizen science UAV
  approach the manual is built on.
- Converted from the working Word document to Markdown so the manual is
  versioned, diffable and served directly on the NCDP website.
